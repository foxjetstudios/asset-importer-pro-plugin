# Asset Importer Pro

Quickly import and preview Roblox assets by ID or a URL right inside of Roblox Studio.
No need to use insertservice in command bar anymore.

---

## Features

* Import Roblox assets from an ID or URL
* Preview the asset before importing
* Custom import destination
* Visual feedback with logs

---

## Usage

1. Open Asset Importer Pro from the Plugins tab
2. Paste a Roblox asset URL or numeric ID
3. Choose your destination instance
4. Click Preview to check the asset (optional)
5. Click Import to add it directly to your game
6. Clear logs anytime using the trash button

---

## How It Works

* Extracts numeric asset ID from URL or input
* Fetches the asset info and thumbnail
* Previews asset with name, creator, description, and thumbnail
* Imports asset into your chosen destination

---

## Requirements

* Script injection permissions MUST be enabled
